# Plates: real Fumadocs UI captures

`app/` is a standalone Next.js app on the published Fumadocs packages. `app/capture/` drives it with
Playwright (headless Chromium) and writes the captured plates to `out/`. The MV serves `out/` at
`/plates/...`, and `out/manifest.json` indexes every plate.

| package | version |
|---|---|
| fumadocs-core | 16.17.1 |
| fumadocs-ui | `npm:@fumadocs/base-ui@16.17.1` |
| fumadocs-mdx | 15.4.7 (macro `defineDocs`, like the current template) |
| fumadocs-openapi / @fumadocs/story / fumadocs-obsidian | 12.4.1 / 1.4.0 / 1.0.6 |
| next / react | 16.3.8 / 19.3.0 |

## Run the app

```bash
cd plates/app
pnpm install
pnpm dev            # http://localhost:5310  (all captures were made against this)
# or: pnpm build && pnpm start   (renders pixel-identical, checked on 4 pages)
```

## Routes

Each theme preset gets its own root layout (route group `app/(t-<id>)/`), so a page loads exactly
one preset's CSS, the way a real app would. The groups are generated by
`pnpm gen` (`scripts/gen-routes.mjs`).

| route | what |
|---|---|
| `/themes/<preset>/<slug>` | Docs layout, preset = neutral, black, vitepress, dusk, catppuccin, ocean, purple, solar, emerald, ruby, aspen, shadcn, or `orange` (neutral + `--color-fd-primary: #FA8023`, used by READ/TOC) |
| `/themes/<neutral\|orange\|ocean>/x/<kind>/<slug>` | kind = notebook, notebook-top (`nav.mode: 'top'` + `tabMode: 'navbar'`), notebook-navbar (`tabMode: 'navbar'`), flux, glass, spacious |
| `/themes/<neutral\|orange\|ocean>/x/home` | Home layout + hero |
| `/docs/<slug>` | Docs layout, neutral (same as `/themes/neutral`) |
| `/openapi/planets/createPlanet` | fumadocs-openapi with the Scalar Galaxy spec (`openapi/galaxy.yaml`) |
| `/obsidian/Welcome` | fumadocs-obsidian, vault in `public/vault` (the example vault + "Fumadocs Vault") |
| `/labels` | method labels with fumadocs-openapi's badge classes, used for the alpha crops |

Query parameters on doc pages:

- `?toc=normal|clerk|block`: `tableOfContent.style`.
- `?single=1`: `tableOfContent.single`.
- `?v=sidebar,clerk,banner,serif,mono`: the customisation demos for the CLI scene
  (`components/variant.tsx`, `styles/variants.css`).

Pages worth knowing:

- `content/docs/getting-started/introduction.mdx`: the hero page. Its h2/h3/h4 are the film's chapters.
- `quick-start.mdx`: the LAYOUT page.
- `themes.mdx`: the THEME/CLI page. Its code block substitutes `__PRESET__` with the route's preset,
  inside the real Shiki token.
- `integrations/story.mdx` and `integrations/sanity.mdx`.

Search is the built-in one (`/api/search?base=<route base>`), so results stay inside the current
theme/layout route.

## Capture

The dev server must be running (`PLATES_URL`, default `http://localhost:5310`).

```bash
cd plates/app
node capture/run.mjs <task> [<task> ...]
```

| task | output (under `out/`) |
|---|---|
| `read:p0` | `read/<orange-light\|neutral-light\|neutral-dark>/frame.png`, `layers/*.png`, `boxes.json` (1440x810 @2x) |
| `read:tall` | `read/orange-light/tall/{alpha,opaque}-NN.png` (+ `tall@1x`) |
| `read:search` | `read/orange-light/search-contents/`: open animation, every typed prefix, ArrowDown, after Enter |
| `read:extras` | tabs states, copy button states, DPR-4 close-ups |
| `read:toc-states` | TOC layer after jumping to each heading |
| `toc:variants` `toc:glass` `toc:mobile` `toc:spacious` `toc:seq` | TOC geometry, stills and sequences |
| `layouts:dark` `layouts:light` | `layouts/<kind>.png` + `.boxes.json` + region layers (1440x900 @2x) |
| `themes` `themes:s600` | `themes/<preset>-<mode>.png` + boxes (1600x900 @2x) |
| `cli:layouts` `cli:variants` `cli:files` | `cli/...` (ocean dark, 1600x900 @2x) |
| `int:openapi` `int:story` `int:obsidian` `int:sanity` | `integrations/...` (dark, 1920x1080 @2x) |
| `interactions` | theme toggle and sidebar folder sequences |
| `manifest` | rebuild `out/manifest.json` from `out/_fragments/` |

Every task writes manifest fragments to `out/_fragments/` and rebuilds `out/manifest.json`
atomically (temp file + rename). `capture/manifest-head.json` holds the header: versions,
conventions and group descriptions.

How the capture stays deterministic (`capture/lib.mjs`):

- Chromium runs with `--force-color-profile=srgb --hide-scrollbars --disable-lcd-text`, locale
  en-US, timezone UTC. Theme mode comes from `localStorage.theme` + `colorScheme`.
- Before each capture: wait for `document.fonts.ready` and decode every image (lazy images are made
  eager). Carets are transparent. Finite running animations are finished; infinite ones (pulse,
  rainbow banner) are paused at t=0. The mouse is never moved unless an interaction needs it.
- Layers: one style tag hides everything except the selected subtree, using `visibility` plus
  `transition: none`, because a visibility transition would keep the element visible. The
  screenshot is taken with a transparent background. `capture/qa-composite.mjs` checks that the
  layers composite back to the frame; READ's set measured max error 2/255.
- Sequences: CDP `Animation.setPlaybackRate(0)` freezes the document timeline. The interaction is
  then triggered, and every animation it created is seeked with WAAPI (`currentTime`), so each
  frame is an exact sample of the real CSS transition. A slow-motion stretch is recorded as
  `stretch` in the manifest.

QA helpers:

- `node capture/validate.mjs`: every file the manifest references exists, and PNG sizes match `size`.
- `node capture/contact.mjs <out.png> <cols> <cellWidth> <img...>`: contact sheet over a checkerboard.
- `node capture/crop.mjs`: crop a region of a PNG.
- `node capture/probe.mjs <path>`: dump a DOM outline with rects.
- `node capture/shot.mjs <path> <out.png> [w h mode dpr]`: quick look (`FULL=1` for the full page).

## CLI transcript

`out/cli/transcript.json` is recorded from real runs. Each step is an exact screen with ANSI colours.

```bash
cd plates/app
export WORKDIR=$(mktemp -d)
python3 capture/cli/ptyrun.py capture/cli/create-app.json $WORKDIR/create-app.jsonl   # npm create fumadocs-app
python3 capture/cli/ptyrun.py capture/cli/customize.json  $WORKDIR/customize.jsonl    # npx @fumadocs/cli customize
python3 capture/cli/ptyrun.py capture/cli/add.json        $WORKDIR/add.jsonl          # npx @fumadocs/cli add
node capture/cli/replay.mjs $WORKDIR/create-app.jsonl 100 34 0.25 > $WORKDIR/create-app.frames.json
node capture/cli/replay.mjs $WORKDIR/customize.jsonl  100 60 0.25 > $WORKDIR/customize.frames.json
node capture/cli/replay.mjs $WORKDIR/add.jsonl        100 40 0.25 > $WORKDIR/add.frames.json
python3 capture/cli/build-transcript.py $WORKDIR
```

`ptyrun.py` drives the CLI in a pseudo-terminal. It waits for prompt text and sends keys, and the
key scripts are in the JSON files. `replay.mjs` replays the raw stream through `@xterm/headless`
and snapshots the screen at every mark.

Use npm for create-app. pnpm 12 refuses unreviewed build scripts, so its install step fails inside
create-fumadocs-app.

## Notes

- Sanity needs a hosted project, so `integrations/sanity` shows the same Fumadocs blocks a Sanity
  page renders through, not live data.
- Search highlights use `::highlight(fd-search)`. Lightning CSS warns about it in production
  builds; dev renders it, and the search captures come from dev.
- The Galaxy API is mocked in the playground capture (Playwright `route`): 201, plus ~120ms of
  latency for the response state.
